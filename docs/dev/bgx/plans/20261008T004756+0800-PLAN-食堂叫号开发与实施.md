## 1. 目标与范围外

做 REQ 一期 MVP 闭环：登录、多食堂窗口、取号叫号过号取消、管理主数据、WS 推送、大屏+TTS。  
不做：点餐支付、SSO、原生 App/小程序、实体叫号器、时长预测。  
需求已定稿。此后规则变更须改 REQ 条目，主要影响 T05/T07/T12。

## 2. 任务

路径均为**拟定**，仓库里尚无这些文件。规模：小 <1 模块日量级；中 数模块；大 跨端+验证。不承诺日历工期。

### T01 选定栈并建骨架

- 目标：可运行的空 API + Web + 合同包。  
- 需求：无直接 R，支撑全部。  
- 产物：`apps/api`（Go + chi）、`apps/web`（Vue 3 + Vite）、`api/openapi.yaml`、README 开发启动说明。  
- 前置：用户授权实施。  
- 要点：按 SPEC C；环境变量示例不含真实密码；先落地 openapi.yaml 空壳。  
- 验证：本地启动 API 健康检查与 Web 空白页。  
- 完成定义：两进程能起，无业务。  
- 风险：栈改选则重建骨架。规模：中。状态：已验证。

### T02 数据模型与迁移

- 需求：R07 R11 R13 R20。  
- 产物：PostgreSQL 迁移：users/canteens/floors/windows/grants/counters/tickets。  
- 前置：T01。

- 验证：迁移可上可下（开发库）。  
- 完成定义：空库 migrate 成功。规模：中。状态：已验证（up；down 未在共享远端库运行）。

### T05 队列引擎：取号/取消/号段

- 需求：R03 R04 R09 R10（取消部分）。

- 完成定义：测试通过且日志含 ticket_id。规模：大。状态：待实施。

### T06 员工叫号完成过号暂停

- 需求：R06 R15 R07（D21）。

- 验证：无授权失败；有 called 时 call-next → CALLED_PENDING；窗口 `closed` 时不可新取号但可叫当日 waiting。  
- 完成定义：状态机 waiting/called/completed/skipped 可走通。规模：中。状态：待实施。

### T07 自动过号调度
