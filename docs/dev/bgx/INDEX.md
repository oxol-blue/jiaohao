## 目标

学校食堂纯排队叫号三端系统：多食堂/多楼层、自建学号登录后看窗口与取号、叫号、管理员可配置过号时长、窗口网页大屏（展示令牌）+ 浏览器语音、WebSocket 推送。打烊后可叫完当日已取号。设计容量约 1 万账号、高峰 2000–3000 在线。一期不做点餐支付与实体叫号硬件。
